# Quest Log Controls

A WoW Forever addon that adds native tracking and collapse controls directly into the Quest Log.

## Features

- Zone checkboxes: each zone header gets a native quest log checkbox aligned vertically with the individual quest checkboxes beneath it, showing tracked, partial, or untracked state.
- Track and Untrack All: a matching top bar checkbox aligned above the checkbox column toggles tracking for every quest in your log.
- Collapse and Expand All: a native plus/minus toggle aligned above the header collapse buttons collapses or expands every section in one click.
- Zero extra bars or panels: fits cleanly beside the quest count without reducing quest list scroll height.

## Usage

1. Open the Quest Log with L or M.
2. Click the top plus/minus button to collapse or expand all sections.
3. Click the top checkbox to track or untrack all quests.
4. Click any zone header checkbox to track or untrack all quests in that zone.

Type `/qlc help` for commands, or `/qlc intro` to replay the first-run tip.
